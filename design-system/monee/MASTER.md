# Monee 設計系統・街頭貼紙版

> **定案**：2026-10-21（取代 2026-10-06 的極簡版）　**視覺參考**：boomboombrothers.tokyo
> **範例畫面**：`monee-home-pop.html`（B 全開版）、`monee-mascot.html`（三個角色）
>
> - 數值以 [`tokens.css`](tokens.css) 為準，這份文件說明每個 token 的用途和使用規則。
> - [`styleguide.html`](styleguide.html) 還是舊的極簡版，之後再更新；有出入時以這份文件和 tokens.css 為準。

---

## 1. 設計原則

1. **貼紙貼在牆上。** 深色模式（預設）是黑色牆面配噴漆色點；淺色模式是奶油紙配網點。卡片、按鈕、面板這些「貼紙」不分深淺都是淺色，有粗黑框和錯開的實心影。
2. **顏色大膽，但每個顏色有用途。** 角色色用在分類、帳戶、角色和漫畫格；黃色是主要按鈕、目前分頁、收入；紅色鋸齒徽章只給「＋」。
3. **有個性，但金額一定好讀。** 卡通字（Luckiest Guy）只用在英文點綴和首頁的今日花費；其他金額用 Rubik 粗體等寬數字。
4. **狀態不能只靠顏色。** 超支、快用完了一定搭配文字、正負號或角色表情。
5. **不給壓力。** 超支的文案用鼓勵語氣，角色冒汗但不罵人，並給出下一步，例如「沒關係，明天起每天可花 $712」。
6. **金額可以隱藏。** 每個顯示金額的畫面都要支援隱藏，隱藏時顯示 `$ ••••`。

## 2. 色彩

### 2.1 頁面（底色與直接放在底色上的字）

| Token | 深色（預設） | 淺色 | 用途 |
|---|---|---|---|
| `--bg` | `#141416` | `#FFF3CF` | 頁面底色 |
| `--bg-dots` | 白 6% | 墨 9% | 底色上的網點 |
| `--bg-spray` | 粉紅、藍綠、黃三團噴漆 | 無 | 固定在畫面上的色點 |
| `--text` | `#F7F3E8` | `#1A1A1E` | 頁面上的標題、文字 |
| `--text-2` | `#BDB9AE` | `#55535C` | 頁面上的說明、日期 |

### 2.2 貼紙（卡片、面板、按鈕、輸入框）：深淺模式都一樣

| Token | 色碼 | 用途 |
|---|---|---|
| `--ink` | `#1A1A1E` | 粗框、實心影、貼紙上的字和圖示 |
| `--ink-2` | `#4E4C55` | 貼紙上的次要文字 |
| `--surface` | `#FFFFFF` | 卡片、按鈕 |
| `--surface-2` | `#FFF9E8` | 底部面板、空狀態框 |
| `--fill` | `#F1ECDD` | 圖示底、進度軌、小卡 |
| `--cream` | `#FFE98A` | 收入小卡 |
| `--line` / `--line-strong` / `--dash` | `#E4DECC` / `#CFC8B2` / `#A9A390` | 貼紙裡的細線、虛線 |

**規則**：`.card`、`.sticker`、`[role="dialog"]`、`.pill`、按鈕、輸入框這些元件會把 `--text`、`--text-2` 換成 `--ink`、`--ink-2`，也重新指定一次 `color`（字的顏色是繼承算好的值，只換變數不夠）。直接放在頁面上的色塊（例如分帳頁的「朋友欠你」小卡、示範模式的提示）一定要加 `.sticker`，不然深色模式下會變成米白字配淺色底。

### 2.3 角色色：分類、帳戶、角色、漫畫格

| Token | 色碼 | 用在 |
|---|---|---|
| `--yellow` | `#FDE021` | 主要按鈕、目前分頁、收入（薪資、其他收入）、硬幣小子 |
| `--teal` | `#00A5B5` | 餐飲、首頁今日卡片、開關打開、英文點綴的影子 |
| `--blue` | `#2C8CDB` | 交通、銀行、鍵盤焦點框 |
| `--green` | `#2DB45A` | 日用、投資收益、現金 |
| `--hot` | `#FF3A81` | 購物 |
| `--purple` | `#8C7FD0` | 娛樂、信用卡、月預算進度 |
| `--red` | `#E1131E` | 醫療、＋ 鋸齒徽章 |
| `--orange` | `#FF9F1C` | 獎金、投資帳戶 |
| `--pink` | `#FF8FB8` | 朋友往來、塗鴉小字 |
| `--brown` | `#C46A2B` | 自己加的分類 |

- 圖示底（`.ico`）用角色色，**圖示一律墨色**：白色圖示在藍綠、綠色上只有 2.7～3.0:1，墨色在每個角色色上都 ≥ 3.6:1。
- 自己加的分類照分類 id 從同一組顏色挑一個（`colorFor`），每次都一樣。「其他」用 `--fill`，轉帳是透明加虛線。
- 要在角色色上放白字時，改用深一階的 `--teal-deep`（4.7:1）、`--purple-deep`（5.9:1）。

### 2.4 狀態（都放在貼紙上，深淺模式一樣）

| 狀態 | 進度條 | 標籤 | 角色表情 | 文案範例 |
|---|---|---|---|---|
| 節奏剛好（剩餘 ≥ 20%） | `--teal` | 白底、粗框 | 咧嘴笑 | 還能花 $390 |
| 快用完了（剩餘 < 20%） | `--warn` | `--warn-tint` 底、`--warn-text` 字 | 波浪嘴＋冒汗 | 只剩 $90 |
| 超支（剩餘 < 0） | `--alert` | `--alert-tint` 底、`--alert` 字 | 張大嘴＋兩滴汗 | 超出 $1,190 |

**交易類型**：支出 `−$260`、收入 `+$48,000` 都用 `--text`，靠正負號和分類圖示區分；轉帳用 `--text-2`、虛線圖示，副標題最前面寫「不算支出」。負號用 `−`（U+2212）。

**投資漲跌**：預設「紅漲綠跌（台股）」，漲用 `--alert` / `--alert-tint`；可以改成「綠漲紅跌」用 `--gain` / `--gain-tint`。一律加 ▲▼ 和正負號。

### 2.5 對比檢查（WCAG AA：一般文字 ≥ 4.5、圖形 ≥ 3）

| 組合 | 對比 |
|---|---|
| `--text` / `--bg` | 深色 16.6、淺色 15.7 |
| `--text-2` / `--bg` | 深色 9.4、淺色 6.8 |
| `--ink` / `--surface` | 17.3 |
| `--ink-2` / `--surface`、`--fill`、`--surface-2` | 8.4、7.1、8.0 |
| `--ink` / `--yellow` | 13.1 |
| `--ink` / `--teal`（今日卡片上的字） | 5.8 |
| 導覽列文字 `#F7F3E8` / `--ink`；目前分頁 `--yellow` / `--ink` | 15.6；13.1 |
| `--warn-text` / `--warn-tint` | 5.4 |
| `--alert` / `--alert-tint`；`--alert` / `--surface` | 4.6；5.9 |
| `--gain` / `--gain-tint` | 5.5 |
| 焦點框 `--blue` / `--bg`（圖形） | 深色 5.2、淺色 3.2 |

> 首頁今日花費是黃字（`--yellow`）放在藍綠底上，本身只有 2.25:1，**一定要有 2.5px 的墨色描邊和實心影**（`.fun-text`），描邊對兩邊都 ≥ 5.8:1。不要把卡通黃字用在沒有描邊的地方。

## 3. 字體

| 用途 | 字體 | 字重 | 載入 |
|---|---|---|---|
| 中文標題、按鈕、分類 | **粉圓 Huninn** | 400 | Google Fonts `<link>`（中文分片多，不用 next/font） |
| 內文 | **Noto Sans TC** | 400 / 500 / 700 | Google Fonts `<link>` |
| 金額、數字 | **Rubik** | 600 / 700 / 800，`tabular-nums` | next/font |
| 英文點綴、首頁今日花費 | **Luckiest Guy** | 400，全大寫 | next/font |
| 塗鴉小字（只當裝飾） | **Sedgwick Ave Display** | 400 | next/font |

- 全站開啟 `font-feature-settings: "palt"`。
- 粉圓只有一種字重；需要強調時用尺寸和顏色，不要用假粗體。

### 3.1 字級

| Token | 大小 | 用在 |
|---|---|---|
| `--fs-display-xl` | 56px | 首頁今日花費（Luckiest Guy，`.fun-text`） |
| `--fs-display-l` | 36px | 本月結餘（Rubik 800） |
| `--fs-display-m` | 30px | 淨資產 |
| `--fs-title-l` | 26px | 頁面標題（粉圓） |
| `--fs-title-m` | 21px | 面板標題 |
| `--fs-title-s` | 18px | 區塊標題 |
| `--fs-body` | 15px | 列表標題、內文 |
| `--fs-body-s` | 13px | 說明句、連結 |
| `--fs-caption` | 12px | 日期、輔助資訊（最小字級） |

### 3.2 寫法

- **英文點綴**（`.en`，例如 OCTOBER、RECENT）：Luckiest Guy 全大寫，字用 `--text`，`--teal` 當錯開 2px 的影子。只是裝飾，旁邊一定有中文標題。
- **泡泡字 Logo**（`BubbleLogo`）：MONEE 五個字母各一個角色色、各歪一點、粗黑描邊。
- **大金額**：`$` 縮成上標；Rubik 用 800 字重。小金額的 `$` 跟數字同大小。

## 4. 間距

以 4px 為格線：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`（`--space-1` 到 `--space-10`）。頁面左右邊距 20px，區塊之間 20px，卡片內距 20px，列表列最低 64px，底部捲動留白 128px（避開導覽列）。

## 6. 粗框與實心影

- **粗框**：`--border` 2.5px 墨色；小元件（篩選膠囊、圖示底、頭像）2px。
- **實心影**：往右下錯開，不模糊。`--pop` 4px（卡片、按鈕）、`--pop-sm` 3px（小元件）、`--pop-lg` 6px（漫畫格）。
- **深色模式**：墨色影子在黑底上看不到，`--pop` 外面多一圈 2px 米白，像貼紙的切邊。
- **按下**：有實心影的東西按下去是「壓扁」：往右下移 2px、影子縮成 1px。其他可點的東西 `scale(.98)`。
- **漫畫格**：`.panel`（3px 框、`--pop-lg`）＋稍微傾斜（`--tilt` 約 −1.5°～1°）。只給主角用：首頁今日卡片、年度回顧、分帳提醒。表單、列表不要傾斜。
- 面板打開時背後蓋 `--scrim`。不要用模糊、漸層陰影。

---

## 7. 圖示

- 圖示庫：**Lucide**，線條粗細 1.5（列表）、2（導覽、按鈕）、3（＋）。
- 尺寸：16（行內）／20（列表、按鈕）／22（底部導覽）／30（＋）。
- 列表圖示底：42×42、圓角 12、2px 墨框，底色見 2.3，圖示墨色。
- 「我的」頁每一列的小圖示（30×30）各用一個角色色。
- 不要用 emoji 當圖示。圖示旁邊有文字時加 `aria-hidden="true"`；只有圖示的按鈕一定要有 `aria-label`。

## 8. 動態

| 用途 | 時間 | 曲線 |
|---|---|---|
| 按下 | `--dur-press` 120ms | 壓扁或 `scale(.98)` |
| 淡入淡出（toast、遮罩） | `--dur-fade` 180ms | ease-out |
| 面板進場 | `--dur-enter` 320ms | `--ease-out` |
| 面板退場 | `--dur-exit` 220ms | `--ease-in`（退場比進場快） |
| 開關的圓點 | `--dur-press` | `--ease-bounce`（彈一下） |
| AI 整理中的角色 | 1s 來回 | 左右搖（`wiggle`） |

開啟「減少動態效果」時，所有時間歸零、搖晃停掉（tokens.css 與 globals.css 已處理）。

## 9. 元件

### 主要按鈕
- 膠囊形，高 52px，黃底（`--primary`）黑字，2.5px 墨框、`--pop` 影子，粉圓 17px。

### 次要按鈕 / 篩選膠囊
- 次要按鈕高 44px，白底、2.5px 墨框、`--pop-sm`，粉圓 14px。
- 篩選膠囊 2px 框、2px 影子；選中時黃底。左右滑的膠囊列（`.pills`）四周留 2～5px，影子才不會被切掉。

### ＋ 按鈕（記一筆）
- 72×72 紅色鋸齒徽章（`SealShape`，16 個尖角、粗黑框、錯開的黑影），白色 ＋，浮在導覽列上方 40px。
- 下方「記一筆」文字，`aria-label="記一筆"`。

### 底部導覽
- 黑色長條（`--ink` 底、2.5px 墨框、`--pop`），白字；目前分頁是黃字，圖示後面墊黃色膠囊，加 `aria-current="page"`。
- 5 格：首頁、明細、＋、資產、報表。「我的」放在頁面右上角的頭像。

### 卡片
- 白底、2.5px 墨框、`--radius-lg`、`--pop`，內距 20px。

### 今日卡片（首頁主卡）
- 漫畫格：藍綠底（`--teal`）、3px 框、`--pop-lg`、傾斜 −1.5°。
- 上區：「今天花了」→ 今日花費（`.fun-text` 黃字黑描邊，56px）→ 鼓勵句。字一律墨色。右上角是使用者挑的角色，表情跟著狀態；右下角塗鴉小字（keep it up! / easy now… / it's ok!）只是裝飾，`aria-hidden`。
- 下區：白底，3px 墨色分隔線；進度條和今日額度、狀態標籤。

### 進度條
- 高 14px、2px 墨框、`--fill` 軌道，填色和軌道之間也有 2px 墨線。
- 月預算進度條上的「今天」標記：4×22px 墨色直條，外面包 2px 白邊。

### 列表列
- 最低 64px：圖示底 → 標題（15px）＋副標題（12px `--text-2`）→ 金額（Rubik）。
- 標題和副標題太長時用省略號；最重要的資訊放副標題最前面。

### 開關（SwitchRow）
- 整列都是按鈕（`role="switch"`），名稱是畫面上的標題、說明用 `aria-describedby`。
- 開關本身 54×32、2px 墨框；打開時軌道藍綠、圓點黃色。

### 底部面板
- 上緣圓角 24px、2.5px 墨框、`--surface-2` 底，上方 48×6 墨色把手。
- 標記 `role="dialog"` 和 `aria-modal`；打開時背景設 `inert`，焦點移進面板；按 Esc 或點遮罩可以關閉。

### Toast
- 黃底黑字膠囊、2px 墨框、`--pop-sm`，粉圓 14px，顯示 2.4 秒。

## 10. 角色

三個角色，使用者在「我的 → 外觀」挑（存在這支手機的 localStorage，預設硬幣小子）。實作在 `web/src/components/Mascot.tsx`，向量圖、可以放大縮小。

| 角色 | 造型 |
|---|---|
| 硬幣小子 | 金色硬幣臉，反戴藍綠鴨舌帽、墨鏡、缺一顆牙的咧嘴笑，帽子側邊有 $ 布章 |
| 錢包兄弟 | 方形紫色錢包，紅毛帽、大眼睛，嘴裡叼一張鈔票 |
| 豬撲滿 | 粉紅撲滿，藍頭巾、墨鏡，頭頂投幣孔 |

- **表情**：`ok` 節奏剛好、`tight` 快用完了（波浪嘴＋汗）、`over` 超支（張大嘴＋兩滴汗；錢包兄弟的鈔票飛走）、`yay` 慶祝（大笑＋星星）。
- **出現位置**：首頁今日卡片（跟著預算狀態）、頭像、登入頁（慶祝）、年度回顧（慶祝）、AI 整理中（搖晃）、群組沒有花費（剛好）／都結清了（慶祝）、分享連結失效（超支）。
- 都是裝飾，`aria-hidden`；旁邊一定有文字說明狀態。
- **App 圖示**：硬幣小子在藍綠網點底上（圖示上的帽子改藍色，跟底色分開）；maskable 版本角色縮在中間 66%。

## 11. 無障礙

- 所有可點的東西至少 44×44px。
- 用真正的 `<button>` 和 `<a href>`，不要在 `<div>` 上綁點擊事件。
- 鍵盤焦點：`outline: 3px solid var(--blue); outline-offset: 3px`。
- 狀態不能只靠顏色，一定搭配文字、正負號或圖示。
- 支援「減少動態效果」；深淺色由使用者在「我的 → 外觀」切換，預設深色。
- 不要禁止使用者放大頁面（viewport 不要加 `user-scalable=no` 或 `maximum-scale=1`）。

---

## 12. 不要做

- 不要在一般支出用紅色。
- 不要把卡通字、塗鴉字用在內文、表單或列表；大金額之外的數字一律 Rubik。
- 不要在沒有描邊的地方用黃字、白字配角色色。
- 不要在角色色上放白色圖示，一律墨色。
- 不要傾斜表單、列表；傾斜只給主角卡片。
- 不要用模糊陰影、漸層按鈕；影子一律實心、往右下錯開。
- 不要讓直接放在頁面上的色塊少了 `.sticker`（深色模式會變成米白字配淺底）。
- 不要用 emoji 當圖示。
- 不要直接寫色碼，一律引用 token（角色的向量圖除外）。
